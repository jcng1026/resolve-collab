## Candidate outbound channel: `Execute` + error log

The bridge would send each message as `fusion:Execute("error(" .. literal .. ")")`, and the companion tails `ResolveDebug.txt`.

- **For:** works on Free today; written immediately; the bridge loop keeps running.
- **Against:**
  - It relies on a side effect, not a documented feature.
  - It writes ERROR lines into Resolve's own debug log.
  - The log rotates at each restart, and its size limits are unknown.
  - Message size limits are unknown.
  - Blackmagic could change it in any update.

Not yet measured: maximum message size, messages per second, behaviour when logs rotate, and whether `Execute` works the same from a menu script as from the Console.
